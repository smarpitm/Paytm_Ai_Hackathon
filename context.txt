- Transaction: id, customer_id (FK customers.id, nullable), tx_type ("UDHAAR_GIVEN" | "UDHAAR_SETTLED" | "UPI_SALE"), item_name, quantity_text, amount (float), is_settled (bool), raw_voice_transcript, source_channel ("SOUNDBOX" | "TELEGRAM"), created_at (datetime)
- DiscountBroadcast: id, item_name, discount_offer, message_text, recipients_count (int), created_at (datetime)
- MerchantStats: id, merchant_name, merchant_upi_id, credit_score (int), pre_approved_loan_amount (int), updated_at (datetime)

## 4. FROZEN REST API & WEBSOCKET CONTRACT (`backend/main.py` <-> `frontend/src/lib/api.js`)
- `POST /api/v1/voice/process-audio` (multipart `audio`) -> returns VoiceEventPayload
- `POST /api/v1/voice/process-text` (`{"text": str, "source": "SOUNDBOX"}`) -> returns VoiceEventPayload
- `POST /api/soundbox/nightly-brief` (`{}`) -> returns NightlyBriefPayload & broadcasts `NIGHTLY_BRIEF`
- `GET /api/v1/erp/dashboard` -> returns `{"summary_metrics": {...}, "customers": [...], "transactions": [...], "broadcasts": [...], "credit_score": {...}, "api_pool_status": {...}}`
- `POST /api/v1/khata/remind/{customer_id}` (`{}`) -> generates UPI QR & sends Telegram reminder
- `POST /api/v1/webhooks/upi-settlement` (`{"customer_id": int, "amount": float, "tx_id": int|None}`) -> settles Khata, bumps Credit Score, synthesizes TTS, broadcasts `UPI_PAYMENT_RECEIVED`
- `POST /api/v1/broadcast/discount` (`{"item_name": str, "discount_text": str, "custom_message": str|None}`) -> saves & sends Telegram broadcast, broadcasts `BROADCAST_SENT`
- `POST /api/v1/demo/reset` (`{}`) -> calls `seed_database(db)` & `reset_session()`, broadcasts `DEMO_RESET`
- `WS /ws/events` envelope:
  `{"event_type": "VOICE_PROCESSED|UPI_PAYMENT_RECEIVED|NIGHTLY_BRIEF|BROADCAST_SENT|DEMO_RESET", "timestamp": str, "soundbox_state": "IDLE|LISTENING|PROCESSING|SPEAKING|ALERT_SUCCESS", "transcript": str, "parsed_intent": dict, "reply_text": str, "tts_audio_base64": str, "conversation_session_state": "IDLE|AWAITING_DISAMBIGUATION|AWAITING_NEW_CUSTOMER_PHONE", "qr_preview_base64": str|None}`
